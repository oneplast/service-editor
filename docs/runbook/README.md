# Runbook 운영 메모

이 디렉토리는 장애, 오류, 설정 문제, 반복 실수 축에서 실패·복구 신호가 확인됐을 때 읽는 예방·점검·복구 문서를 보관한다.

## 무엇을 여기에 두는가

- 로컬/개발 환경에서의 재현 절차
- 관련 축 작업 전에 먼저 확인할 체크포인트
- 장애 점검 순서
- 확인해야 할 로그, 쿼리, 엔드포인트
- 환경 설정 확인 항목
- 복구/우회 방법
- 반복되는 문서 작업 실수와 그 복구 절차
- 반복되는 검증 실패 케이스와 그 복구 절차

## 작성 기준

- 가능한 한 다시 따라 하면 같은 문제를 재현하거나 같은 점검을 수행할 수 있게 적는다.
- 전역 규칙 자체를 새로 정의하지 않고, 그 축에서 자주 깨지는 체크포인트와 다시 볼 원문 링크만 남긴다.
- 각 runbook은 가능하면 상단에 `빠른 진입점`을 두고, 현재 증상에서 먼저 볼 섹션과 추가 확인 조건을 짧게 연결한다.
- 명령, 로그 위치, 선행 조건, 기대 결과를 같이 적는다.
- "안 되면 다시 해본다" 같은 모호한 표현보다 확인 포인트를 구체적으로 적는다.
- 실제 디버깅 흐름이 바뀌면 같은 작업에서 runbook도 갱신한다.
- 같은 실패 축이 확인되면 관련 runbook 파일에 케이스를 추가하거나 기존 케이스를 바로 보강하는 것을 기본으로 한다.
- 기존 실패 축에 넣을지 새 축을 만들지 애매하면 자동으로 새 runbook을 만들지 않고, 후보 안을 정리해 사용자 확인을 받는다.

## 선택 기준

- 문서 체계, followup, topic, `.codex` 작업에서 읽기 순서, 경로 분류, 규칙 중복, 복구 상태가 흔들릴 때 [docs/runbook/ai-doc-workflow-recovery.md](https://github.com/oneplast/service-editor/blob/dev/docs/runbook/ai-doc-workflow-recovery.md)를 읽는다.
- 구현 검증, 테스트, Gradle 빌드에서 실제 실패가 발생했거나 알려진 반복 실패의 예방 체크포인트가 직접 필요할 때 [docs/runbook/test-verification-recovery.md](https://github.com/oneplast/service-editor/blob/dev/docs/runbook/test-verification-recovery.md)를 읽는다.
- 장애 재현, 설정 오류, 환경 점검처럼 기능 또는 환경 자체를 다시 확인해야 하는 경우에는 해당 문제 유형 runbook만 추가로 읽는다.
- runbook 전체를 넓게 읽지 않고, 현재 증상과 직접 연결된 파일 하나를 먼저 읽는 것을 기본 원칙으로 한다.
- 선택한 runbook 안에서는 먼저 `빠른 진입점` 또는 현재 증상과 가장 가까운 분기 섹션만 확인하고, 원인 분류나 복구 절차가 부족할 때만 앞뒤 섹션을 추가로 읽는다.
- 정상 작업에서는 runbook을 선행 로드하지 않는다.
- 세션 재개 시에는 followup으로 현재 상태를 먼저 맞추고, 실패·복구 신호가 남아 있을 때만 관련 runbook으로 분기한다.
- 반복 실수 분기와 검증 실패 기록 절차는 관련 skill/script를 따른다.

## 반복 케이스 반영 기준

- 같은 주제 runbook 안에 이미 가까운 증상 항목이 있으면, 그 파일 안에 새 케이스를 추가하거나 기존 항목을 보강한다.
- 완전히 다른 문제 축이면 새 runbook 파일을 만든다.
- 반복 에러를 runbook 반영 없이 끝내지 않는다. 반영하지 않는다면 이유를 남겨야 한다.
- 메인 에이전트가 실패 축과 runbook 게이트를 확정했고 runbook에 아직 항목이 없다면 첫 실패 처리 시점에 바로 추가한다.
- 실패 축이 애매하면 자동 생성 대신 후보 안을 제시하고 사용자 확인을 받는다.
- 일반 실패 사례를 추가하거나 보강하는 것만으로 문서 거버넌스 검증이나 prompts 기록을 자동 활성화하지 않는다.
- runbook 체계·운영 규칙·workflow 계약이 바뀌면 `doc-governance`, 같은 목표의 기록이 이미 활성화됐거나 프로젝트 단위 기록 가치가 있으면 `prompts`를 각각 별도로 판정한다.
